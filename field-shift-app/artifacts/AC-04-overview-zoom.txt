AC-04 overview tier at its own last zoom, round 2 rework, branch block5/one-string-per-state

ROOT CAUSE. src/lib/polygon-source.ts set both overview layers' `maxzoom` to the tier's
`overview_maxzoom`. A MapLibre layer draws while `minzoom <= z < maxzoom`, so the layer stopped one
zoom short of its own range: the United States overview (3 to 5) drew at 3 and 4 only, and the Brazil
overview (5 to 7) drew at 5 and 6 only. The detail tier is unchanged: no `maxzoom`, so it overzooms
above 14 (R-05).

FIX. `layerMaxzoomFor(tier)` returns `tier.maxzoom + 1`, and both overview layers take it. The tier
numbers themselves stay the contract (Table G for the United States, Table B for Brazil), and the
overview's layer range now ends exactly where the detail's begins.

METHOD. Running app (vite dev server, backend on :8000, both build files present), real MapLibre,
CDP 1440x900, one page load per region, `queryRenderedFeatures` over `polygon-overview-fill` and
`polygon-fill` after `idle`. The "old range" rows are the same page with the previous layer range
restored on it with `map.setLayerZoomRange`, which is the value the gate measured.
